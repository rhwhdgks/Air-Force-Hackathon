# AI 기반 실시간 무단투기 감지·맞춤형 쓰레기통 배치 통합 플랫폼

제7회 공군 창의·혁신 아이디어 공모 해커톤 지정공모 과제인 “깨끗한 거리 조성을 위한 쓰레기 무단투기 감소 대책” 제안 프로젝트입니다.

본 프로젝트는 CCTV 기반 무단투기 감지, 공간정보 기반 무단투기 발생 예측, 쓰레기통 배치 최적화, 웹 기반 실시간 시각화를 하나의 통합 플랫폼으로 연결하는 것을 목표로 합니다.

## 추진 배경

기존 무단투기 대응은 사후 민원 처리와 정기 단속에 크게 의존합니다. 이 방식은 민원 접수 이후 개별 대응까지 시간이 걸리고, 담당 인력의 반복 업무 부담도 큽니다.

또한 단속용 CCTV와 쓰레기통 설치가 확대되어도 무단투기 문제는 계속 발생하고 있습니다. 따라서 민원과 단속 결과에 사후 대응하는 방식보다, 공간정보 데이터를 기반으로 위험 지역을 예측하고 쓰레기통을 효율적으로 배치하는 체계가 필요합니다.

## 목표

- AI 기반 CCTV 영상 분석으로 무단투기 상황을 실시간 감지합니다.
- 유동인구, POI, 도로, 기존 쓰레기통, 단속 이력 등 공간정보 데이터를 통합합니다.
- Multi-Scale Regression과 Random Forest를 활용해 무단투기 발생량을 예측합니다.
- K-Means, Greedy, 1·2-swap 탐색을 활용해 제한된 개수의 쓰레기통 배치안을 도출합니다.
- Flask 기반 웹 대시보드에서 지도, 시뮬레이션, 진행률, 배치 결과를 시각화합니다.

## 현재 저장소 구현 범위

이 저장소는 제안서의 전체 통합 플랫폼 중 **공간분석 기반 쓰레기통 배치 시뮬레이터와 지도 시각화 파트**를 구현한 코드입니다.

구현되어 있는 기능은 다음과 같습니다.

- 강남구 격자별 쓰레기 발생 추정량 데이터 로드
- 기존 쓰레기통, CCTV, 단속 지점 등 지도 레이어 제공
- 쓰레기통 개수, 설치 반경, 지점당 최대 설치 수를 입력받는 시뮬레이션 API
- Greedy + 1·2-swap 기반 배치 최적화
- Server-Sent Events(SSE)를 통한 진행률 및 결과 스트리밍
- 시뮬레이션 결과를 지도 오버레이로 시각화

제안서에 포함된 YOLOv8 기반 CCTV 무단투기 감지 서버, SENS API 문자 알림, PostgreSQL/PostGIS 통합 DB, Airflow 기반 ETL 파이프라인은 이 저장소의 현재 구현 범위에는 포함되어 있지 않습니다.

## 기술 개요

### 무단투기 예측

제안서에서는 유동인구, 상업/비상업 POI, 도로 접근성, 기존 쓰레기통, 단속 이력 등 공간정보 데이터를 위치 기반 공통키로 정제한 뒤, 분석 포인트마다 Gaussian kernel을 적용해 거리 가중치를 반영합니다.

이후 Multi-Scale Regression으로 각 독립변수의 영향 반경을 탐색하고, 선별된 변수를 Random Forest 지도학습 모델에 입력해 무단투기 발생량을 예측합니다.

### 쓰레기통 배치 최적화

배치 최적화는 제한된 수의 쓰레기통으로 무단투기 감소 효과를 높이는 것을 목표로 합니다.

- K-Means로 밀집 지역 중심의 후보지를 선별합니다.
- Greedy 방식으로 초기 배치안을 빠르게 생성합니다.
- 1·2-swap 탐색으로 지역 최적화를 반복 수행합니다.
- 설치 반경 내 중복 설치 금지, 동일 지점 최대 설치 수 같은 제약조건을 반영합니다.

### 웹 시뮬레이터

Flask 서버가 최적화 알고리즘을 실행하고, SSE로 진행률과 결과를 브라우저에 전달합니다. 정적 지도 화면은 Kakao Maps 기반 HTML 파일과 JSON/GeoJSON 데이터를 사용합니다.

## 프로젝트 구조

```text
.
├── app.py                  # Flask 애플리케이션 진입점
├── data/gangnam/           # 원본 및 가공 CSV/GeoJSON 데이터
├── map/                    # 앱에서 직접 읽는 JSON/GeoJSON 지도 데이터
├── scripts/                # 데이터 가공, 후보지 생성, 시각화 스크립트
│   └── legacy/             # 이전 Flask 서버 버전
├── static/                 # HTML 지도, 이미지, 비디오 정적 파일
├── Project Overview.pdf    # 프로젝트 요약 자료
├── Project Proposal.pdf    # 프로젝트 제안서
└── requirements.txt        # Python 의존성
```

## 실행 방법

Python 3.9 이상을 권장합니다.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

서버 실행 후 브라우저에서 접속합니다.

```text
http://localhost:8080
```

## 주요 엔드포인트

- `/` : 최종 지도 및 쓰레기통 배치 시뮬레이터 화면
- `/gangnam` : 강남구 CCTV 포함 지도 화면
- `/api/markers` : 강남구 마커 GeoJSON 반환
- `/api/cctvs` : CCTV 위치 JSON 반환
- `/api/runGreedyStream?n=1000&r=50&max=1` : 쓰레기통 설치 시뮬레이션 실행
- `/api/overlayStream` : 시뮬레이션 결과 오버레이 SSE 스트림
- `/api/latestOverlay` : 최근 시뮬레이션 오버레이 결과

## 데이터

앱은 실행 시 `map/pred_50m_50cap.json`을 기본 격자 데이터로 읽습니다. 시뮬레이션 실행 중 생성되는 `map/coverage_diff.json`은 재생성 가능한 결과물이므로 Git 추적 대상에서 제외했습니다.

주요 데이터는 강남구를 대상으로 구성되어 있으며, 제안서상 전체 시스템은 서울시 전역으로 확장 가능한 구조를 목표로 합니다.

## 기대 효과

- 무단투기 감지 및 대응 업무의 자동화로 행정 업무 부담을 줄입니다.
- 데이터 기반 쓰레기통 재배치로 무단투기와 관련 민원 감소를 기대할 수 있습니다.
- CCTV, 단속 이력, 공간정보 데이터를 함께 활용해 지자체 예산 수립과 정책 판단의 근거를 제공합니다.
- 향후 스마트 쓰레기통, 수거 일정 최적화, 다른 도시 공공시설 입지 선정 문제로 확장할 수 있습니다.
